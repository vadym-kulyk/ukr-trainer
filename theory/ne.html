Частку не пишемо окремо, коли вона лише заперечує, і разом, коли разом зі словом творить нове поняття або слово без «не» не вживається (Правопис, § 44).

Головне питанняЧи можна замінити слово з «не» синонімом без «не»? неправда = брехня, невеселий = сумний → разом. Чи є протиставлення з «а», пояснювальні слова з «ні», «зовсім», «аж ніяк»? → окремо.

  • Разом із займенниками та прислівниками: ніхто, нічий, ніщо, ніякий; ніде, нізащо, нізвідки, ніколи, нікуди, ніскільки, нітрохи, ніяк.

Алгоритм

  1. Чи вживається слово без «не»?Ні → разом (ненависть, нехтувати).
  2. Яка частина мови?Дієслово, дієприслівник → окремо. Дієприкметник → крок 4.
  3. Іменник, прикметник, прислівникЄ «а», «зовсім», «аж ніяк», ні-слова → окремо. Можна замінити синонімом → разом.
  4. ДієприкметникПрисудок або є пояснювальні слова → окремо. Означення без залежних слів → разом.
