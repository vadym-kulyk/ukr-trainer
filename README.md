# Мовний тренажер Midgard

Тренажер з української мови для учнів: 28 тем (фонетика, орфографія, лексикологія), докладна теорія за підручниками (з мнемоніками, «пастками НМТ» і самоперевіркою) та по 100 завдань з автоматичною перевіркою в кожній темі. Норми — «Український правопис» (2019).

Окремий розділ **«Завдання ЗНО»** — 2606 завдань ЗНО/НМТ (2077 унікальних) у 51 темі з поясненнями та детальною теорією до кожної теми.

Розділ **«Симуляція НМТ»** — 33 тести (29 тренувальних варіантів і 4 авторські) по 30 завдань: 60 хвилин, «Зберегти відповідь», підсумок у тестових балах (0–45) і за шкалою 100–200 за офіційною таблицею 2026 року, розбір з поясненнями й теорією.

На будь-якій сторінці можна виділити слово й одразу подивитися його значення на slovnyk.ua (кнопка «Словник» угорі теж відкриває пошук). Під час виконання завдань теми теорія відкривається кнопкою «Теорія» внизу екрана.

Сайт статичний і працює на GitHub Pages. Результати учнів надходять у Google Таблицю вчителя.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | сторінка та логіка інтерфейсу |

| `data-extra.js` | додаткові теми: уподібнення, чергування, ненаголошені звуки, н/нн, складні слова разом і через дефіс |
| `engine.js` | генератор 100 завдань для кожної теми та перевірка відповідей |
| `config.js` | адреса таблиці результатів |
| `img/` | ілюстрації (згенеровані на Hugging Face, Z-Image Turbo) і знаки Midgard |
| `google-apps-script/Code.gs` | скрипт, що записує результати в Google Таблицю |
| `zno-app.js` | розділ «Завдання ЗНО»: список тем, завдання трьох типів, перевірка, пояснення |
| `zno/index.json`, `zno/t/*.json` | банк ЗНО: перелік тем і завдання кожної теми (згенеровано скриптом) |
| `zno/img/` | картинки до завдань ЗНО |
| `zno/theory/*.html` | теорія до тем ЗНО за підручниками (теми з фонетики, орфографії й лексики використовують теорію тренажера) |
| `tools/import_zno.py` | конвертер банку `ukrmova.json` → `zno/` (також оновлює список тем у `Code.gs`) |
| `tools/check_zno.py` | перевірка цілісності даних: ЗНО, НМТ, теорія тренажера |

| `nmt/index.json`, `nmt/t/*.json`, `nmt/img/` | тести НМТ, таблиця переведення балів, картинки |
| `tools/import_nmt.py` | імпорт тестів НМТ із zno.osvita.ua (з прив’язкою завдань до тем теорії) |

## Крок 1. Опублікувати сайт

1. Завантажте вміст цієї папки в репозиторій GitHub.
2. **Settings → Pages → Build and deployment**: Source — `Deploy from a branch`, Branch — `main`, папка `/ (root)`.
3. За хвилину сайт відкриється за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Крок 2. Підключити Google Таблицю для результатів

1. Створіть нову Google Таблицю (наприклад, «Результати — тренажер»).
2. **Розширення → Apps Script**. Видаліть код, що там є, і вставте вміст `google-apps-script/Code.gs`. Збережіть.
3. **Розгорнути → Нове розгортання** → тип **Веб-застосунок**:
   - «Виконувати як»: **Я**;
   - «Хто має доступ»: **Усі**.
4. Натисніть «Розгорнути» і дозвольте доступ до таблиці. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`).
5. Відкрийте `config.js` і вставте цю адресу:
   ```js
   window.MG_CONFIG = { resultsUrl: "https://script.google.com/macros/s/…/exec" };
   ```
6. Збережіть зміну в репозиторії, і сайт почне надсилати результати.

У таблиці з’являться два аркуші:

- **«Результати»** — один рядок на учня: загальний відсоток, кількість виконаних завдань і відсоток за кожну тему. Рядок оновлюється після кожної відповіді.
- **«Спроби»** — кожна відповідь учня окремим рядком: час, учень, тема, номер спроби теми (зростає після «Почати тему заново»), номер і тип завдання, запитання, відповідь учня, правильна відповідь і результат.

- **«ЗНО»** — один рядок на учня: загальний результат ЗНО та відсоток за кожну тему ЗНО. Кожна відповідь у ЗНО також потрапляє на аркуш «Спроби» (тема з позначкою «ЗНО»).
- **«НМТ»** — один рядок на учня: скільки тестів пройдено, найкращий бал 100–200, а для кожного тесту — найкращий і останній результат, кількість спроб і виходів зі сторінки під час тесту. Кожна завершена симуляція потрапляє й на аркуш «Спроби».

### Оновлення скрипта

Якщо змінили `Code.gs`, вставте новий код в Apps Script, збережіть і виберіть **Ввести в дію → Керувати введеннями в дію → ✏️ → Версія: «Нова версія» → Ввести в дію**. Адреса `/exec` лишається тією самою.

## Профілі учнів

Учень створює профіль: ім’я, прізвище, клас і PIN-код (4–6 цифр). Увійти можна з будь-якого пристрою, і весь прогрес завантажиться з таблиці.

- PIN зберігається лише у вигляді хешу на аркуші **«Профілі»**.
- Після 8 невдалих спроб вхід у профіль блокується на 15 хвилин.
- **Учень забув PIN:** на аркуші «Профілі» очистіть клітинку «PIN (хеш)» у його рядку. Під час наступного входу учень задасть новий PIN.
- Без входу прогрес не можна ні прочитати, ні перезаписати.

## Симуляція НМТ

- Як на справжньому НМТ: правила, підтвердження, кнопка «Розпочати роботу над тестом», таймер 60 хвилин (можна сховати), усі 30 завдань на одній сторінці, «Зберегти відповідь» біля кожного, панель номерів (збережені зафарбовані), підсумкове вікно зі списком незбережених завдань.
- Логічні пари: торкніться картки з буквою, потім рамки біля цифри (на комп’ютері можна перетягувати).
- Зараховуються лише збережені відповіді. Завдання 1–25 — 1 бал, 26–30 — до 4 балів (по 1 за пару); максимум 45. Бал 100–200 — за офіційною таблицею (менше 8 балів — поріг не подолано).
- Таймер іде навіть після закриття сторінки; повернувшись, учень потрапляє в той самий тест. Виходи зі сторінки під час тесту рахуються.
- Під час тесту словник і теорія вимкнені. Після тесту — розбір кожного завдання з поясненням і кнопкою теорії до теми.
- Завдання й пояснення взято з zno.osvita.ua (з прямими посиланнями на джерело на кожній сторінці тесту). Оновити:

```bash
python3 tools/import_nmt.py --fetch /шлях/до/кешу
```

- Результати НМТ надсилаються в таблицю після оновлення скрипта до версії 6 (`SERVICE_VERSION = 6`).

## Завдання ЗНО

- Угорі головної сторінки — вкладки **«Тренажер»** і **«Завдання ЗНО»**. Теми ЗНО можна виконувати в будь-якому порядку.
- Типи завдань: один правильний варіант, кілька правильних (цифри), установлення відповідності. Після відповіді учень бачить, правильно чи ні, правильну відповідь і пояснення.
- Відсоток теми = правильні завдання / усі завдання теми; максимум — 100 %. Загальний підсумок рахується за унікальними завданнями (одне завдання може входити в кілька тем).
- Результати ЗНО надсилаються в таблицю лише після оновлення скрипта до версії 5 або новішої (`SERVICE_VERSION` у `Code.gs`), доти вони чекають на пристрої учня.

Оновити банк із джерела:

```bash
python3 tools/import_zno.py "/шлях/до/ukrainian/zno"
python3 tools/check_zno.py
```

Після імпорту, якщо змінився список тем, оновіть скрипт у таблиці (див. «Оновлення скрипта»).

## Як це працює для учня

- Учень входить у профіль угорі сторінки, обирає будь-яку тему, читає теорію й виконує завдання. Теорію можна читати й без входу.
- Кожне правильне завдання дає 1 %, у темі можна набрати 100 %.
- Прогрес зберігається в профілі (у таблиці вчителя). Після кнопки «Вийти» на пристрої нічого не лишається.
- Якщо інтернету немає, прогрес лишається на пристрої й надсилається пізніше. Є кнопка «Скопіювати звіт» для ручного надсилання.

## Обмеження

- Будь-хто може створити профіль із вигаданим ім’ям. Таблицю бачите лише ви.
- Профіль визначають ім’я, прізвище й клас. Якщо в одному класі є повні тезки, попросіть одного з них додати до прізвища букву.
